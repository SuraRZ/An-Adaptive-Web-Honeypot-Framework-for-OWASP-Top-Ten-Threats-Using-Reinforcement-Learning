# Adaptive Web Honeypot for OWASP Top Ten Threats Using Reinforcement Learning

A deceptive Flask web application that uses a Q-learning agent to adaptively
respond to attacker behavior across the OWASP Top 10 vulnerability categories.
Built as part of an academic cybersecurity research project.

## Overview

The honeypot (`honeypot_flask.py`) poses as a corporate web portal and logs
every request. Instead of using static, pre-scripted decoys, an underlying
Q-learning agent (`qlearning_engine.py`) selects a deception action for each
interaction based on the attacker's observed behavior, dynamically steering
the engagement to maximize information gathered about the attacker.

**Key design elements:**
- Reinforcement learning modeled as an MDP with 7 states across three
  progression stages (surface, structural, and privileged) and a terminal state
- 10 OWASP Top Ten attack categories (A01–A10) used for request classification
- 8 distinct deceptive actions the agent can choose between
- A custom reward function balancing engagement depth, transition quality,
  and penalty for suboptimal actions
- Persistent Q-table (`qtable.json`) and JSON event logging
  (`honeypot_events.json`) for offline analysis

## Project structure

| File | Purpose |
|---|---|
| `honeypot_flask.py` | Flask app — deceptive endpoints, session tracking, request classification, event logging |
| `qlearning_engine.py` | Q-learning agent — state/action model, reward function, training loop |
| `qtable.json` | Trained Q-table (sample, generated by the engine) |
| `honeypot_events.json` | Sample interaction log from a local test run |

## Setup & usage

```bash
pip install flask

# Optional: pre-train the agent before running the app
python qlearning_engine.py --train 10000

# Run the honeypot
python honeypot_flask.py
```

## Testing the classifier

Once the app is running (`python honeypot_flask.py`), you can send requests
to see how they're classified against OWASP Top 10 categories. A few
examples:

```bash
# A01 — Broken Access Control
curl http://localhost:5000/admin/dashboard

# A03 — Injection
curl "http://localhost:5000/api/v1/query"

# A05 — Security Misconfiguration
curl http://localhost:5000/.env

# A07 — Authentication Failures
curl -X POST http://localhost:5000/api/v1/auth/login

# A10 — SSRF
curl "http://localhost:5000/api/v1/fetch?url=http://169.254.169.254/"
```

Each request is classified, logged to `honeypot_events.json`, and triggers
the agent to select a deceptive response. The full set of monitored routes
per category is defined in `honeypot_flask.py`.

## Notes

This project was built and tested against local/simulated traffic only, as
part of academic cybersecurity research. It is intended for authorized
research and educational use — not for deployment against real, unconsented
traffic.
